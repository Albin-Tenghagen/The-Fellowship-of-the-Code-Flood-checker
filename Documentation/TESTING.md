# Testing

## Embedded testing

For the embedded system we did not use a etsting framework, but instead we tested our code directly on the Heltec board since it was easier to check if sensor values are correct. We checked if the code could be build and then asked the member with access to the hardware if they could test the code. However, this method was very timeconsuming and a little bit more complicated since we needed to try and reach out about code testing. We also modified the main function to test our code, this also led to merge conflicts but it worked.
